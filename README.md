# 🎭 Whimsical Name Generator

Transform any name into a magical pseudonymous monicker!

## ✨ What it does

Enter a person's name and get a whimsical, pseudonymous version that preserves the first two letters of each word. Perfect for creating fun aliases, character names, or just adding some magic to everyday names!

**Example:**
- Mark Doolittle → Magnificent Doberman
- Jane Smith → Joyful Smiling
- Alice Brown → Angelic Brilliant

## 🎨 Features

- **Large Dictionary**: 200+ positive, whimsical, and friendly words
- **Smart Matching**: Preserves the first two letters of each name part
- **Beautiful UI**: Gradient design with smooth animations
- **Easy to Use**: Just type a name and press Enter or click Generate
- **Input Validation**: Only accepts valid names (letters and spaces)

## 🚀 Try it out

Visit the live demo: [Whimsical Name Generator](https://rudeyak.github.io/pseudo-pseudonymizer/)

## 💻 How it works

1. Enter any name in the input field
2. The app extracts the first two letters of each word
3. Randomly selects a matching whimsical word from the dictionary
4. Displays your new magical pseudonym!

## 🛠️ Technology

Pure HTML, CSS, and JavaScript - no dependencies required! Just open `index.html` in any modern web browser.
